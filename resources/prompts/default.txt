2. **HTML Rules:**

   - Colors, spacing, typography cơ bản → Dùng Tailwind

4. **JS Rules - CẤU TRÚC BẮT BUỘC:**
   ```javascript
   // 1. CONSTANTS & CONFIG
   const CONFIG = {
     canvas: { width: 800, height: 600 },
     colors: { primary: '#3b82f6', secondary: '#8b5cf6' }
   };
   
   // 2. STATE MANAGEMENT
   const state = {
     current: 'idle', // idle, running, paused, complete
     step: 0,
     progress: 0,
     data: {}
   };
   
   // 3. ENTITY CLASSES (nếu cần)
   class Entity {
     constructor(x, y) {
       this.x = x;
       this.y = y;
     }
     update(dt) { /* ... */ }
     draw(ctx) { /* ... */ }
   }
   
   // 4. RENDERING
   function render() {
     ctx.clearRect(0, 0, canvas.width, canvas.height);
     // Draw logic
   }
   
   // 5. UPDATE LOOP
   let lastTime = 0;
   function animate(currentTime) {
     const dt = (currentTime - lastTime) / 1000;
     lastTime = currentTime;
     
     if (state.current === 'running') {
       update(dt);
     }
     
     render();
     requestAnimationFrame(animate);
   }
   
   // 6. EVENT HANDLERS
   function handleStart() { /* ... */ }
   function handleReset() { /* ... */ }
   
   // 7. INITIALIZATION
   function init() {
     // Get DOM elements
     const canvas = document.getElementById('mainCanvas');
     const ctx = canvas.getContext('2d');
     
     // Setup canvas
     canvas.width = CONFIG.canvas.width;
     canvas.height = CONFIG.canvas.height;
     
     // Bind events
     document.getElementById('btnStart').onclick = handleStart;
     document.getElementById('btnReset').onclick = handleReset;
     
     // Start animation loop
     requestAnimationFrame(animate);
   }
   
   // 8. CALL INIT
   init();
   ```

   NGHIÊM CẤM:
   - localStorage, sessionStorage
   - jQuery hoặc external libraries (trừ Tailwind)
   - async/await cho animations (dùng requestAnimationFrame)
   - setInterval/setTimeout cho physics (dùng deltaTime)

**YÊU CẦU TƯƠNG TÁC - QUAN TRỌNG:**

1. **State Machine:** 
   - Bắt buộc có biến `state` với các trạng thái rõ ràng
   - Ví dụ: { current: 'idle|running|paused|complete', step: 0, ... }

2. **Step-by-Step:**
   - Chia bài học thành các bước logic
   - Gọi `window.initSteps([...])` để tạo hướng dẫn
   - Gọi `window.updateActiveStep(index)` khi đổi bước

3. **Visual Feedback:**
   - Mỗi hành động phải có phản hồi trực quan (đổi màu, animation, số liệu)
   - Canvas phải cập nhật smooth (60fps nếu có thể)
   - Buttons phải có hover/active states

4. **Knowledge Integration:**
   - Gọi `window.updateTheory({title, formula, explanation, tip})` để hiển thị kiến thức
   - Công thức dùng LaTeX syntax (sẽ được MathJax render)

5. **Progress Tracking:**
   - Gọi `window.updateStatus(text, icon, percentage)` để cập nhật trạng thái
   - Progress bar phải phản ánh đúng tiến độ
